# 12週間コンパス

12週間の目標に対する日々の実行を記録するためのアプリ。モチベーションを上げるためのものではなく、やったことの証拠を残し、実行率だけを見るためのもの（Phase1）。

- ローカルで完結するPWA（オフライン動作、サーバー・API連携なし）
- 認証不要、1ユーザー専用
- データはブラウザのlocalStorageに保存

## 学習機能（Phase2）

『学び方の学び方』のアドバイスのうち、効果の大きい2つを実行の記録に組み込んでいる。

- **ポモドーロ**：25分集中 → 5分休憩。集中が終わると「できた証拠」に自動で記録される。途中でやめた分は記録しない
- **想起テスト**：学んだことを1問1答で登録すると、1日 → 3日 → 7日 → 14日 → 30日 → 60日の間隔で出題される。思い出せなかったカードは翌日から出題し直す

どちらも日ごとの回数が残り、過去の週の内訳から振り返れる。想起カードはバックアップにも含まれる。
